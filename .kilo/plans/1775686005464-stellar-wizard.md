# Plan: Menambahkan Console Log untuk Debugging Register

## Tujuan
Menambahkan console.log debugging di backend untuk melacak alur register dari controller hingga service.

## File yang Perlu Dimodifikasi

### 1. `backend/src/modules/auth/auth.controller.ts`
Tambah console.log di fungsi `register`:
- Saat menerima request body
- Setelah sanitasi email
- Saat validasi role
- Saat upload gambar
- Saat cek existing user
- Saat membuat user baru
- Saat error terjadi

### 2. `backend/src/modules/auth/auth.service.ts`
Tambah console.log di fungsi `register`:
- Saat menerima data register
- Saat proses hashing password
- Saat generate referral code
- Saat create user di Prisma
- Saat proses referral (jika ada)
- Saat transaction selesai
- Saat error terjadi

## Catatan
- Beberapa console.log sudah ada di kode, perlu diperluas untuk debugging yang lebih komprehensif
- Gunakan format `[DEBUG] authController.register - ...` dan `[DEBUG] authService.register - ...`
