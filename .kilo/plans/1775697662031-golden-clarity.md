# Comprehensive Event Endpoints Test Plan
All endpoints base path: `/api/events`

---

## 1. GET /
**Description**: Get all events with filtering, sorting, and pagination

### Test Scenarios:
✅ Valid request with default pagination
✅ With search parameter
✅ With category filter
✅ With location filter
✅ With date range filter (startDate, endDate)
✅ With price range filter (minPrice, maxPrice)
✅ With sortBy and sortOrder
✅ With pagination (page, limit)
❌ Invalid date format
❌ Invalid price values
❌ Invalid sortBy field

### Curl Command:
```bash
# Basic request
curl -X GET http://localhost:3000/api/events

# With filters
curl -X GET "http://localhost:3000/api/events?search=music&category=concert&location=jakarta&minPrice=0&maxPrice=100000&page=1&limit=10&sortBy=startDate&sortOrder=asc"

# With date range
curl -X GET "http://localhost:3000/api/events?startDate=2024-01-01&endDate=2024-12-31"
```

### Expected Response:
✅ **200 OK**:
```json
{

      "endDate": "2024-06-02T00:00:00.000Z",
      "totalSeats": 1000,
      "availableSeats": 500,
      "price": 50000,
      "imageUrl": "...",
      "organizer": { "id": "...", "fullName": "...", "profilePicture": "..." },
      "tickets": [...]
    }
  ],
  "pagination": {
    "page": 1,

    "total": 50,
    "totalPages": 5
  }
}
```

## 3. POST /
**Description**: Create new event (Organizer only)

### Test Scenarios:
✅ Valid data with all required fields
✅ With optional availableSeats
✅ With image file upload
❌ Missing required fields
❌ Invalid date format
❌ Invalid numeric values (negative price, zero seats)
❌ startDate after endDate
❌ Not an organizer (no auth token)
❌ Invalid auth token

### Curl Command:
```bash
curl -X POST http://localhost:3000/api/events \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <ACCESS_TOKEN>" \
  -d '{
    "name": "Music Concert 2024",
    "description": "An amazing music concert",
    "location": "Jakarta Convention Center",
    "category": "concert",
    "startDate": "2024-06-01T18:00:00.000Z",
    "endDate": "2024-06-01T23:00:00.000Z",
    "totalSeats": 1000,
    "price": 50000,
    "availableSeats": 1000
  }'
```

### Expected Response:
✅ **201 Created**:
```json
{
  "success": true,
  "message": "Created event successfully",
  "data": {
    "id": "uuid",
    "name": "Music Concert 2024",
    "description": "An amazing music concert",
    "location": "Jakarta Convention Center",
    "category": "concert",
    "startDate": "2024-06-01T18:00:00.000Z",

    "availableSeats": 1000,

```

## General Test Notes:
- All endpoints return standard `{ success: boolean, data?: object, message?: string }` format
- POST / PUT endpoints require `Content-Type: application/json` header
- Protected endpoints require `Authorization: Bearer <access_token>` header
- Organizer role required for: POST, PUT, DELETE, GET /me
- Event images uploaded to Cloudinary via `imageFile` form field
- Pagination default: page=1, limit=10, max limit=100
- Valid sortBy fields: name, startDate, price, createdAt
- Deleted events (isDeleted: true) should not be returned in GET / and GET /:id
